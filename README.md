# Node.js CI/CD Pipeline using GitHub Actions

## Objective
Automate build and deployment using GitHub Actions and Docker.

## Tools Used
- GitHub
- GitHub Actions
- Node.js
- Docker
- DockerHub

## Workflow
1. Code pushed to GitHub
2. GitHub Actions triggers pipeline
3. Dependencies installed
4. Docker image built
5. Image pushed to DockerHub

## Output
Automated CI/CD pipeline for Node.js application.
